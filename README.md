# ตัวแปลงหน่วย

เว็บแปลงอุณหภูมิ เงินตรา และระยะทาง สร้างด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build

## ใช้งานในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง

## Deploy บน Vercel

1. Import Git repository นี้จากหน้า Vercel
2. เลือก **Framework Preset: Other**
3. ตั้งค่า Build Command และ Output Directory เป็นค่าว่าง
4. กด Deploy

Vercel จะให้ URL สำหรับเข้าใช้งานทันที และจะ deploy เวอร์ชันใหม่อัตโนมัติทุกครั้งที่ push ไปยัง branch หลัก
