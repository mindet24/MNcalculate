ดึงอัตราแลกเปลี่ยนล่าสุดจาก API

ไม่ใช้ตัวเลขคงที่ที่ฝังไว้ในโค้ด แต่เรียกบริการอัตราแลกเปลี่ยนทุกครั้งที่เปิดหน้าเว็บ เพื่อให้ได้ข้อมูลล่าสุด ณ ตอนนั้น

02

มีระบบสำรองเมื่อดึงข้อมูลไม่สำเร็จ

ถ้าเน็ตหลุดหรือ API ใช้งานไม่ได้ เว็บจะสลับไปใช้อัตราประมาณสำรองโดยอัตโนมัติ แทนที่จะแสดงหน้าเปล่าหรือพัง

03

คำนวณผลลัพธ์ทันทีที่พิมพ์

ไม่ต้องกดปุ่ม "คำนวณ" — พิมพ์ตัวเลขหรือเปลี่ยนหน่วยปุ๊บ ผลลัพธ์อัปเดตทันทีด้วย JavaScript ล้วนๆ
